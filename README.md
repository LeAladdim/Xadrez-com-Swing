# Xadrez-com-Swing

Projeto de jogo de Xadrez com UI interativa utilizando Java como base e podendo ser rodado diretamente pela IDE usando Swing.
Algumas funcionalidades implementadas:

° Partidas PVP e PVE (com seletor de dificuldade)

° Gráfico de vantagem por cor

° Notação da partida com feedback de precisão do lance

° Setas de predição de movimento com o botão direito do mouse para auxiliar na previsão de jogadas
